# Crowd Flow Optimiser

A control-room web app for venue operators that simulates crowd flow through a
venue graph, forecasts capacity-driven bottlenecks over time, and produces
plain-language rerouting recommendations on an interactive, colour-coded map.

Built for stadiums, transit stations and mass-gathering grounds where knowing
_where_ and _when_ congestion will peak is the difference between a smooth
egress and a dangerous crush.

## Features

- **Three tuned preset venues** — stadium post-match egress, metro morning
  rush, and a Kumbh-scale festival ground — plus custom JSON layout upload.
- **Macroscopic flow simulation** — a NetworkX graph model steps tens of
  thousands of people through the venue, ranking next-hops by progress toward
  exits and queueing on edge/node capacity.
- **Bottleneck detection** with severity bands (clear / moderate / warning /
  critical) and an estimated clearance time per hotspot.
- **AI rerouting guidance** generated by a Hugging Face instruction model, with
  a rule-based fallback so the console stays useful during cold starts.
- **Interactive canvas map** — heatmap glow, per-status line patterns, node
  shapes by type, hover tooltips, pan & zoom, and an animated alternate-route
  overlay.
- **Time scrubber** with playback (1x/2x/4x) and a severity mini-timeline.
- **Exportable incident briefing** (PDF) and per-step timeline (CSV).
- **Shareable links** — the active preset and scenario are encoded in the URL.
- **Keyboard shortcuts** — `Space` play/pause, `←`/`→` step, `Esc` close panel.

## Tech stack

| Layer     | Choice                                                    |
| --------- | --------------------------------------------------------- |
| Frontend  | React 19 + TypeScript, Tailwind CSS, Zustand, HTML canvas |
| Backend   | FastAPI, NetworkX, NumPy                                  |
| Data      | MongoDB (venues + simulation results)                     |
| AI        | Hugging Face Inference API (`Qwen/Qwen2.5-7B-Instruct`)   |

## Architecture

```
frontend/                  React + TypeScript single-page console
  src/
    components/            Canvas map, header KPIs, control panel, scrubber
    store/simStore.ts      Zustand app state
    services/api.ts        Typed axios client (retry + backoff)
    utils/                 Canvas renderer, report export, colours, URL state
backend/
  server.py                FastAPI routes + Mongo persistence
  simulation.py            Graph build + flow engine + bottleneck detection
  presets.py               Hand-tuned demo venues
  ai_service.py            Hugging Face NLG + fallback templates
  models.py                Pydantic schemas
```

The frontend calls the backend under the `/api` prefix using
`REACT_APP_BACKEND_URL`. Simulation runs are persisted to MongoDB so that AI
suggestions can be requested for any time step after the fact.

## Getting started

### Prerequisites

- Node.js 18+ and Yarn
- Python 3.11+
- MongoDB running locally (or a connection string)
- A Hugging Face access token (free) for AI suggestions

### Environment variables

Copy the examples and fill in your values:

```bash
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
```

| File           | Variable                | Purpose                                  |
| -------------- | ----------------------- | ---------------------------------------- |
| `backend/.env` | `MONGO_URL`             | MongoDB connection string                |
| `backend/.env` | `DB_NAME`               | Database name                            |
| `backend/.env` | `HF_TOKEN`              | Hugging Face Inference API token         |
| `backend/.env` | `HF_MODEL`              | Instruction model for recommendations    |
| `frontend/.env`| `REACT_APP_BACKEND_URL` | Base URL of the backend API              |

### Run

```bash
# backend
cd backend
pip install -r requirements.txt
uvicorn server:app --reload --port 8001

# frontend (in a second terminal)
cd frontend
yarn install
yarn start
```

## API

| Method | Endpoint                     | Description                            |
| ------ | ---------------------------- | -------------------------------------- |
| GET    | `/api/health`                | Service + AI configuration status      |
| GET    | `/api/presets`               | List preset venues                     |
| GET    | `/api/presets/{id}`          | Preset layout + default parameters     |
| POST   | `/api/venues`                | Validate & store a custom layout       |
| GET    | `/api/venues/{id}`           | Fetch a stored layout                  |
| POST   | `/api/simulate`              | Run a flow simulation                  |
| GET    | `/api/simulations/{id}`      | Fetch a stored simulation result       |
| POST   | `/api/reroute-suggestions`   | AI recommendations for a time step     |
