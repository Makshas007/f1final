# Crowd Flow Optimiser — PRD & Build Log

## Original Problem Statement
Build **Crowd Flow Optimiser (CFO)**: a real-time, AI-assisted crowd simulation and rerouting
system for venue operators (stadiums, metro stations, festival grounds). Ingest a venue layout
graph + expected attendance/schedule, simulate people flow over discrete time steps, flag
emerging bottlenecks before they become dangerous, compute alternate routes, and present
plain-language rerouting recommendations generated by a Hugging Face model on an interactive,
color-coded venue map with a time scrubber.

**User choices (confirmed):** Hugging Face Inference API (user-supplied `HF_TOKEN`); all three
preset venues (stadium egress, metro station rush, festival/Kumbh-scale ground); no stretch
features; dark control-room theme (deep navy + glassmorphism).

## Architecture
- **Frontend:** React 19 (CRA) + Tailwind + shadcn/ui + zustand + sonner. Full-bleed HTML5
  Canvas map rendered outside the React cycle via `requestAnimationFrame` (sub-200ms scrubbing).
- **Backend:** FastAPI (`/api` prefix) + NetworkX macroscopic flow engine + MongoDB
  (venues, simulations).
- **AI layer:** `huggingface_hub.AsyncInferenceClient` → `Qwen/Qwen2.5-7B-Instruct`
  (fallback `google/gemma-2-2b-it`, then rule-based templates).

### Key files
| File | Role |
|---|---|

| `backend/presets.py` | 3 hand-tuned demo venues + default scenario params |

| `backend/server.py` | REST API + Mongo persistence |

| `frontend/src/utils/canvasRenderer.js` | Heatmap, node shapes, colorblind patterns, alternate-path overlay |

## Core Requirements (static)
- Layout ingestion (preset + JSON upload) with validation errors surfaced clearly.
- Time-stepped flow simulation with capacity-based bottleneck detection (50/75/90% thresholds).
- Alternate path computation avoiding congested elements.
- HF-generated operator recommendations with graceful degradation.
- Interactive canvas map, heatmap, time scrubber, suggestions panel, accessibility patterns.
- Simulation < 5s; suggestions < 3s (measured: 0.19s / ~1.1s).
